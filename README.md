# CoalFlow — Coal Handling Plant Monitoring Dashboard

A CSE-oriented educational prototype inspired by the Coal Handling Plant workflow studied during an industrial internship. It demonstrates how software can present industrial readings, equipment states, time-series trends, alerts, and CSV reports.

> **Important:** This project uses generated, simulated values only. It is not connected to NTPC, a real plant, any DCS/PLC/SCADA network, or operational equipment. Do not present its sample readings as actual NTPC data.

## Features

- Operations overview with coal flow, belt speed, motor temperature, and stockyard level cards.
- Simplified material flow: receiving → conveying → processing → storage → boiler feed.
- Auto-generated sensor-like readings every 5 seconds.
- Coal-flow trend chart and illustrative warning reference.
- Equipment status list for conveyor, crusher, magnetic separator, drive motor, and bunker supply.
- Alerts generated by demo thresholds, with acknowledge action.
- CSV export of recent simulated readings.
- SQLite storage for local readings and alert history.
- Responsive layout for laptop and mobile screens.

## Tech stack

- Frontend: React, Vite, Recharts, Lucide icons, CSS
- Backend: Python, Flask, Flask-CORS
- Local database: SQLite

## Requirements

- Python 3.10 or newer
- Node.js 18 or newer (Node.js LTS recommended)
- npm (included with Node.js)

## Run on Windows

1. Extract the ZIP file.
2. Double-click `start_windows.bat`.
3. The first launch installs dependencies and may take a few minutes depending on your internet connection.
4. Open [http://localhost:5173](http://localhost:5173) if the browser does not open automatically.

Alternatively, run each part separately:

**Terminal 1 — backend**

```bat
cd backend
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

**Terminal 2 — frontend**

```bat
cd frontend
npm install
npm run dev
```

Open `http://localhost:5173`.

## Run on macOS / Linux

**Terminal 1 — backend**

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

**Terminal 2 — frontend**

```bash
cd frontend
npm install
npm run dev
```

Open `http://localhost:5173`.

## API endpoints

| Method | Endpoint | Purpose |
|---|---|---|
| GET | `/api/health` | API health check |
| GET | `/api/dashboard` | Latest metrics, equipment, alerts, and history |
| POST | `/api/alerts/{id}/acknowledge` | Acknowledge a demo alert |
| GET | `/api/export.csv` | Download simulated readings as CSV |

The API listens on `http://127.0.0.1:5000`; Vite serves the frontend on `http://localhost:5173`.

## How to explain it in your internship presentation

"Based on my study of the Coal Handling Plant workflow, I built an educational monitoring dashboard to demonstrate how industrial parameters can be visualised in software. The prototype generates simulated coal-flow, conveyor-speed, motor-temperature, and stock-level readings. It displays them through cards and charts, maintains a basic equipment view, and raises alerts when demo thresholds are crossed. This is a software prototype for learning and is not connected to NTPC's actual plant systems."
